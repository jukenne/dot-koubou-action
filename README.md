# ドット工房アクション

ドット絵で**部品を自分で作って**、ステージに置いて、友達に挑戦してもらう横スクロールのジャンプアクションです（マリオメーカーのような遊びです）。
部品は「絵 × 動き（往復・回転）× 効果（足場・即死・ゴール）」の組み合わせで、他の部品を組み合わせた大きな部品も作れます。

## ダウンロードと起動（Windows / Mac どちらでも）

1. このページの右側にある **「Releases」** から、最新の `dot-koubou-action-vX.X.X.zip` をダウンロードします
2. zip を**解凍**します
3. 中の **`index.html` をダブルクリック**して、ブラウザ（Chrome / Edge 推奨）で開きます

インストール不要です。遊ばなくなったら、解凍したフォルダを削除すれば消えます。

## 遊び方

1. **あそぶ**：まず見本ステージ「はじめの一歩」で操作に慣れます（← → で移動、Space / Z / ↑ でジャンプ。長押しで高く跳べます。R で最初からやり直し）
2. **部品を作る**：見本部品をいじると、自動でコピーができます。大きさは 16〜80 ドット、他の部品を呼び出して組み立てもできます
3. **ステージを作る**：部品を置いて、「▶ テストプレイ」で**自分でクリア**します（クリアすると共有できるようになります）
4. **共有する**：「📤 共有ファイルを書き出す」で `.dotkoubou.json` ができるので、友達に渡します。もらったファイルは「あそぶ」の「📂 ステージのファイルを開く」（またはウィンドウにドロップ）で開きます

## 保存について

作った部品とステージは、**このブラウザの中**（localStorage）に自動保存されます。

- ブラウザのデータを消すと、作ったものも消えます。大事なステージは**共有ファイルに書き出して**取っておくと安心です
- 別のブラウザ・別のフォルダから開くと、保存内容は引き継がれません（ブラウザごと・開き方ごとに別の保存場所です）
- 友達のファイルを開くと、その人の部品があなたの「自作部品」に追加されます

## 動作環境

PC のブラウザ（Chrome / Edge / Firefox の最近のバージョン）。スマホは想定していません。
